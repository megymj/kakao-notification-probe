# KakaoNotificationProbe

갤럭시에서 카카오톡 알림이 어떤 구조(extras)로 들어오는지 확인하는 PoC 앱입니다.
`com.kakao.talk` 알림만 원문 그대로 앱 전용 저장소(`files/dumps.jsonl`)에 기록합니다.

## 목적과 원칙

- **목적**: 개발자 커뮤니티 오픈채팅방의 대화를 일 단위로 모아 기술 트렌드를 분석하는 프로젝트의 첫 단계입니다. 카카오는 오픈채팅 API를 제공하지 않기 때문에, 본인 기기에 표시되는 알림을 활용할 수 있는지 검증합니다.
- **공식 API만 사용**: Android `NotificationListenerService`로 본인 기기의 알림만 읽습니다. 카카오톡 앱 역분석, 비공식 프로토콜, 서버 접근은 사용하지 않습니다.
- **최소 수집**: 카카오톡 이외 앱의 알림은 읽지도 저장하지도 않습니다. 덤프는 기기 내부 앱 전용 저장소에만 저장하고, 외부 서버로 전송하지 않습니다.
- **참여자 고지**: 테스트는 직접 만든 방이나 참여자에게 알린 방에서만 진행합니다. 확인이 끝난 원문 데이터는 삭제합니다.

## 설치

설치 방법은 두 가지입니다. 코드를 자주 고치는 테스트 기간에는 **방법 A**를 권장합니다.

| | A. Android Studio (USB/무선) | B. APK 파일 |
|---|---|---|
| 처음 설치 | 개발자 옵션 설정 필요 | 자동 차단·출처 허용·제한된 설정 해제 필요 |
| 코드 수정 후 재설치 | ▶ Run 한 번 | 빌드 → 파일 전송 → 설치 반복 |
| 로그 확인 | Logcat으로 바로 확인 | 불가 |

먼저 Android Studio에서 이 폴더를 열고 Gradle 동기화가 끝날 때까지 기다립니다.

### 방법 A. Android Studio로 설치 (권장)

**1. 갤럭시에서 개발자 옵션 켜기 (처음 한 번만)**

1. 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호**를 7번 연속 탭하고 PIN을 입력합니다.
2. 설정 → **개발자 옵션** → **USB 디버깅**을 켭니다.

**2. USB로 설치**

1. 데이터 전송이 되는 USB-C 케이블로 갤럭시를 PC에 연결합니다 (충전 전용 케이블은 인식되지 않습니다).
2. 폰에 "USB 디버깅을 허용하시겠습니까?"가 뜨면 **이 컴퓨터에서 항상 허용**을 체크하고 허용합니다.
3. Android Studio 상단 기기 목록에서 갤럭시 모델명을 선택하고 **▶ Run**을 누릅니다.
4. 앱이 설치되고 실행됩니다. 이후에는 USB를 분리해도 앱은 그대로 남습니다.

**무선으로 설치하려면 (Android 11 이상)**

1. 폰과 PC를 같은 Wi-Fi에 연결합니다.
2. 폰에서 개발자 옵션 → **무선 디버깅**을 켭니다.
3. Android Studio 기기 목록 → **Pair Devices Using Wi-Fi**를 엽니다.
4. 폰의 무선 디버깅 화면에서 **QR 코드로 기기 페어링**을 눌러 PC 화면의 QR을 스캔합니다.

**기기가 목록에 보이지 않으면**

```bash
~/Library/Android/sdk/platform-tools/adb devices
```

- `unauthorized`: 폰 화면의 USB 디버깅 허용 창을 확인합니다.
- 아무것도 나오지 않음: 케이블이나 USB 포트를 바꾸거나, 폰 알림창에서 USB 연결 모드를 **파일 전송**으로 바꿉니다.

Android Studio(adb)로 설치한 앱은 Android 13+의 "제한된 설정" 잠금을 받지 않으므로 알림 접근을 바로 허용할 수 있습니다.

### 방법 B. APK 파일로 설치

1. **APK 빌드**: Android Studio 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
   결과물은 `app/build/outputs/apk/debug/app-debug.apk`입니다.
2. **폰으로 전송**: Google Drive, 나에게 이메일 보내기 등으로 APK를 옮깁니다.
3. **삼성 자동 차단 끄기** (One UI 6 이상): 설정 → 보안 및 개인정보 보호 → **자동 차단** → 끄기.
   켜져 있으면 파일로 설치하는 것 자체가 막힙니다. 설치가 끝나면 다시 켜두는 것을 권장합니다.
4. **설치**: 내 파일이나 Drive에서 APK를 엽니다.
   - "출처를 알 수 없는 앱" 안내가 나오면 해당 앱(내 파일, Drive 등)에 설치를 허용합니다.
   - Play 프로텍트 경고가 나오면 세부정보 → **그래도 설치**를 누릅니다.
5. **제한된 설정 풀기**: 파일로 설치한 앱은 Android 13+에서 알림 접근 권한이 잠겨 있습니다.
   1. 앱에서 **알림 접근 권한 설정 열기** → "Kakao 알림 프로브"를 켜려고 하면 "제한된 설정" 안내가 뜹니다. 이 시도를 한 번 해야 다음 메뉴가 나타납니다.
   2. 설정 → 애플리케이션 → Kakao 알림 프로브 → 오른쪽 위 **⋮** → **제한된 설정 허용**을 누릅니다.
   3. 다시 알림 접근으로 가서 앱을 켭니다.

> 업데이트할 때는 같은 PC에서 빌드한 APK를 사용하세요. 디버그 서명이 같아야 기존 앱 위에 덮어 설치되고, 쌓인 덤프도 유지됩니다.

## 설정

- 앱의 **알림 접근 권한 설정 열기** → "Kakao 알림 프로브" 허용. 앱 상단이 "허용됨 ✅"으로 바뀌는지 확인합니다.
- **배터리 최적화 예외 설정 열기** → 이 앱을 최적화 예외로 지정
- 삼성 기기: 설정 → 애플리케이션 → Kakao 알림 프로브 → 배터리 → **제한 없음**
- 삼성 기기: 설정 → 배터리 → 백그라운드 사용 제한 → "절전 예외 앱"에도 추가 권장
- 카카오톡: 대상 오픈채팅방 알림 켜기, 카카오톡 설정 → 알림에서 메시지 내용 미리보기 켜기

## 테스트

대상 채팅방을 **닫아둔 상태**에서 다른 기기로 메시지를 1건, 이어서 연속 5건 보냅니다.
확인할 것:

- 방 이름이 들어 있는 키: `android.conversationTitle` / `android.subText` / `android.title`
- `messagingStyle.messages`에 이전 메시지가 누적되어 다시 오는지
- 같은 `dedupKey`가 여러 덤프에 반복되는지 (= 중복 제거 키로 쓸 수 있는지)

## 덤프 보기

- 앱 화면: 최근 20건
- **내보내기** 버튼: 공유 시트로 `dumps.jsonl` 전송
- PC에서 (USB 디버깅 연결 필요, 디버그 빌드에서만 동작):

  ```bash
  ~/Library/Android/sdk/platform-tools/adb exec-out run-as dev.probe.kakao cat files/dumps.jsonl > ~/dumps.jsonl
  ```

  덤프에는 메시지 원문이 들어 있으므로 이 저장소 폴더 밖에 저장하세요.

## 개인정보 주의

이 앱은 다른 참여자의 닉네임과 메시지 원문을 기기에 저장합니다.
테스트는 참여자에게 알린 방이나 직접 만든 테스트 방에서 진행하고, 확인이 끝나면 **전체 삭제**로 지워주세요.
